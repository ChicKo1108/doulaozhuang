# Mard 标准色卡与套装

将已确认来源的 Mard 221 色母色卡填入 `data/mard-221.json`。字段为：

- `code`：Mard 官方色号，唯一。
- `name`：Mard 官方色名。
- `hex`：用于界面展示和算法约束的色值。
- `sortOrder`：色卡的展示顺序。

`data/mard-standard-kits.json` 定义 24、48、72、96、120、221 色的标准用色档位，默认项固定为 `mard-221`。MVP 中，小档位基于图片最常出现的 Mard 颜色做二次量化；221 色则使用完整母色卡。若后续取得经确认的实体套装色号清单，可将其扩展为固定色号集合。

色卡提交前执行仓库根目录的 `npm run check:palette`。不要添加未经确认的色号或色值。
