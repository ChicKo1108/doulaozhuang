# 豆老庄视觉设计方向 v1

## 设计主题

**拼豆庄园工坊**：把小程序理解成庄豆豆经营的一座手作庄园。页面不是普通卡片列表，而是由门匾、木案、豆盘、图纸夹和豆仓组成的工作空间。

## 风格拆解

- **形体**：厚实圆角、木雕包边、牌匾式容器，避免轻薄悬浮的通用互联网卡片。
- **材质**：深胡桃木、朱红漆面、奶油宣纸、藤编豆篮；拼豆保持糖果般的圆润高光。
- **色彩**：主色朱砂红 `#C93D24`，结构色胡桃棕 `#542B18`，底色宣纸白 `#FFF7E8`，功能强调松石青 `#168C88`，奖励与数字使用豆黄 `#F6B916`。
- **层次**：外轮廓使用深棕描边，内侧用暖金细线和柔软投影；光源统一从左上方进入。
- **排版**：标题采用厚重、略带手写牌匾感的中文黑体；正文使用清晰现代黑体；色号、颗数等数据采用等宽数字。
- **装饰纪律**：豆子串、流苏和屋檐只用于页面头部、重点统计和完成反馈，不给每个普通控件都加装饰。

## 页面设计思路

### 首页

顶部像庄园门头，中部主统计区是一块朱红木牌。庄豆豆从圆形木门探出，承担“欢迎回来”和库存概览。真实图纸仍是首页主要内容，卡片图片使用柔和的纸张色底，不覆盖重装饰。

### 图纸库

图纸卡片像放在木案上的成品签，保留双列瀑布流。状态不是普通胶囊标签，而是小型木印：未拼为纸白、正在拼为松石青、已拼为豆黄。

### 图纸转换

转换过程被叙述为庄豆豆的制图工序：分析态使用放大镜形象，生成态使用工作台形象，完成态展示拼豆花。参数区域采用简化木框，不让装饰影响尺寸、色档和镜像选择。

### 豆仓

豆仓采用“抽屉/豆罐”语义。库存色块仍以真实 MARD 色为准，木色只用于容器，避免干扰颜色判断。低库存使用朱砂标记，正常库存使用松石青。

### 图纸详情

施工图保持白底与高可读性，不套重纹理。状态操作区可使用牌匾边框；点击“拼完了”后以庄豆豆完工形象完成情绪反馈。

## 后续前端落地原则

1. 先建立颜色、圆角、描边、阴影和字号 Token，再逐页替换。
2. 第一阶段只重做首页、图纸库和图纸详情，确认方向后再覆盖豆仓与个人页。
3. 真实图纸、MARD 色号和库存数字始终优先于装饰。
4. 单屏只允许一个强视觉焦点；庄豆豆不在同一屏重复出现。
5. 低端安卓和微信真机优先使用 PNG 与 CSS 基础阴影，不依赖复杂滤镜。
